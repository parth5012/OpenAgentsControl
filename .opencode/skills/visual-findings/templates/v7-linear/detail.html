XSS / HTML injection via unescaped finding fields

securityopened by ui-auditAug 23, 2026scripts/generate.mjs:360
Severity
critical
Category
security
Location
generate.mjs:360
Source
ui-audit

Description

generate.mjs interpolates title, description, recommendation and tags directly into HTML templates. Only codeSnippet passes through escapeHtml(). A finding containing <script> or raw HTML breaks the page layout and executes arbitrary markup when the report is opened.

Evidence

// current - line 360
<div class="description">
  <p>${finding.description}</p>   // unescaped
</div>

Recommendation

Route every string field through escapeHtml() before interpolation — including title, description, recommendation, category, source and tag values.
