XSS / HTML injection via unescaped finding fields #001

criticalsecurityui-audit
ui-audit opened this finding on Aug 23, 2026 · scripts/generate.mjs:360

Description

generate.mjs interpolates title, description, recommendation and tags directly into HTML templates. Only codeSnippet passes through escapeHtml(). A finding containing <script> or raw HTML breaks the page layout and executes arbitrary markup when the report is opened.

Evidence

// current - line 360
<div class="description">
  <p>${finding.description}</p>   // unescaped
</div>
✓
Recommended fixRoute every string field through escapeHtml() before interpolation — including title, description, recommendation, category, source and tag values.
